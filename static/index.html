      charchat-lab

      AI 캐릭터와 나누는 대화예요. 상대는 사람이 아니에요.

      Enter로 보내고 Shift+Enter로 줄을 바꿔요.

      새 대화

      설정

      새 실험

      입력 대본 하나를 변형(설정 묶음)마다 새 대화에서 처음부터 자동으로 보내요. 변형의 라벨이 실험 라벨이 되어 결과 표의 행을 나눠요.

      변형

      설정 JSON에는 지금 설정에서 바꿀 값만 적어요. 예: {"window_strategy": "full"}, {"input_token_budget": 3000}, {"provider": "openai_compat", "models": {"openai_compat": "qwen3.5:4b"}}

      .env의 제공사 옵션과 프롬프트 파일도 변형마다 바꿀 수 있어요. 예: {"provider_options": {"openai_compat": {"reasoning_effort": "none", "top_p": 0.95}}}(값을 null로 두면 보내지 않아요), {"prompt_overrides": {"final_user": "{input}\n\n<system-memo>\n{lore}{instructions}\n</system-memo>"}}

      실제 제공사의 캐시는 비울 수 없어요. 앞 대화의 캐시가 뒤 대화에 섞이지 않게 하려면 대화 사이 대기를 캐시 수명보다 길게 두세요(Anthropic 기본 5분).

      반복하면 같은 대본을 변형마다 여러 번 돌려 반복 사이의 편차를 함께 보여 줘요. 1회차에 모든 변형, 2회차에 모든 변형 순으로 번갈아 돌고, mock은 회차마다 시드를 하나씩 바꿔요.
